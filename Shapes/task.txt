1. Реализовать класс Shape, который:
    - Имеет приватное поле name
    - публичные методы:
        - конструктор
            (с параметром типа string для имени фигуры)
        - getName()
            (получение имени по константной ссылке)
        - area()
            (расчёт площади фигуры)
        - perimeter()
            (расчёт периметра фигуры)

2. Наследники должны иметь собственные приватные 
   (или защищенные, если требуются в наследнике) 
   поля-характеристики конкретной фигуры и 
   переопределенные варианты area и perimeter

3. У каждого класса должен быть уникальный конструктор
   с достаточным количеством параметров для определения
   фигуры (например, радиус или длины всех сторон)

4. Если создание фигуры с заданными величинами в качестве
   параметров невозможно, то необходимо бросать подходящее
   по смыслу исключение.

5. Каждый класс должен удовлетворять правилу пяти.

6. После реализации семейства классов фигур необходимо
   перегрузить операторы сравнения фигур по площади
   operator== и сравнения фигур по периметру operator^,
   а также оператор вывода operator<<, погружающий в
   поток вывода информацию о фигуре (имя, площадь, периметр).
